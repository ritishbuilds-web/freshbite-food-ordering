# FreshBite – Online Food Ordering

## Project Overview
FreshBite is a frontend food ordering website where users can
browse restaurants, explore food menus, add items to a cart,
and simulate the checkout process.

## Technologies
- HTML5
- CSS3
- JavaScript

## Main Features
- Restaurant listings
- Food categories
- Menu browsing
- Shopping cart
- Quantity adjustment
- Checkout simulation
- User login and registration simulation
- Responsive design

## Project Structure
- index.html – Website structure
- style.css – Website styling
- script.js – Interactive functionality
- assets/images – Website images
